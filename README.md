# AI クイズマスター

AIが自動でクイズを生成するReactアプリケーション。Claude APIを使用して問題を生成し、専門用語のツールチップ、解説画像、履歴保存などの機能を持つ。

## 主要機能

### 1. キーワード検証機能
- 入力されたキーワードをAIが分析
- 有効なキーワード: そのままクイズ生成開始
- 曖昧なキーワード: 候補を5つ表示して選択させる
- 存在しない言葉: エラー表示と修正候補3つを表示
- 不適切なキーワード: エラーメッセージのみ表示

### 2. 問題生成（ストリーミング方式）
- 最初の1問を即座に生成してクイズ開始
- 残りの問題はバックグラウンドで1問ずつ順次取得
- オンデマンド取得: 次の問題がなければその場で取得

### 3. クイズ形式
- 4択問題
- 選択可能な問題数: 3問 / 5問 / 10問
- 中程度〜難しめの難易度
- 過去に出題した問題は重複を避ける（キーワードごとに最大50問を記録）

### 4. 解説機能
- 詳しい解説文
- 専門用語ツールチップ: 解説内の専門用語（2〜4個）をホバー/タップで定義表示
- 解説画像: Unsplashから関連画像を表示
- 参考リンク: Wikipedia等の信頼できるサイトへのリンク

### 5. 履歴・スコア管理
- キーワードごとにグループ化された成績履歴
- 正答率、挑戦回数、平均スコアを表示
- LocalStorageで永続化（最大100件）

### 6. プリフェッチ機能
- クイズ完了後、同じキーワードで次回のクイズを先読み
- 「準備完了」バッジ表示で即座にリプレイ可能

## セットアップ

### 必要条件
- Node.js 18以上
- Claude API キー

### インストール

```bash
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

### ビルド

```bash
npm run build
```

## 使い方

1. アプリを起動し、「設定」タブでClaude APIキーを設定
2. 「クイズ」タブでキーワードを入力して「クイズ開始」をクリック
3. 4択問題に回答し、解説を読む
4. クイズ完了後、結果を確認
5. 「履歴」タブで過去の成績を確認

## 技術スタック
