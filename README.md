# AI クイズマスター

AIが自動でクイズを生成するReactアプリケーション。Claude APIを使用して問題を生成し、専門用語のツールチップ、解説画像、履歴保存などの機能を持つ。

## 主要機能

### 1. カテゴリ選択
- プログラミング基礎、Web開発、データベース、DevOps、セキュリティの5カテゴリ
- カテゴリごとに問題を出題
- 全カテゴリからランダム出題も可能

### 2. キーワード検証機能（APIモード）
- 入力されたキーワードをAIが分析
- 有効なキーワード: そのままクイズ生成開始
- 曖昧なキーワード: 候補を5つ表示して選択させる
- 存在しない言葉: エラー表示と修正候補3つを表示
- 不適切なキーワード: エラーメッセージのみ表示

### 3. 問題生成（ストリーミング方式）
- 最初の1問を即座に生成してクイズ開始
- 残りの問題はバックグラウンドで1問ずつ順次取得
- オンデマンド取得: 次の問題がなければその場で取得

### 4. クイズ形式
- 4択問題
- 選択可能な問題数: 3問 / 5問 / 10問
- 中程度〜難しめの難易度
- 過去に出題した問題は重複を避ける（キーワードごとに最大50問を記録）

### 5. 解説機能
- 詳しい解説文
- 専門用語ツールチップ: 解説内の専門用語（2〜4個）をホバー/タップで定義表示
- 解説画像: Unsplashから関連画像を表示
- 参考リンク: Wikipedia等の信頼できるサイトへのリンク

### 6. 履歴・スコア管理
- キーワードごとにグループ化された成績履歴
- 正答率、挑戦回数、平均スコアを表示
- LocalStorageで永続化（最大100件）

### 7. データ管理
- クイズデータのエクスポート（JSON形式）
- カスタム問題のインポート
- 外部JSONファイルから問題を読み込み

## セットアップ

### 必要条件
- Node.js 18以上
- Claude API キー（オプション - デモモードではなくても動作）

### インストール

```bash
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

### ビルド

```bash
npm run build
```

## GitHub Pages へのデプロイ

このリポジトリはGitHub Pagesで公開できます。

### 自動デプロイ（推奨）

1. GitHubリポジトリの Settings > Pages を開く
2. Source で「GitHub Actions」を選択
3. mainブランチにプッシュすると自動でデプロイされます

デプロイ後のURL: `https://<username>.github.io/testnewRipo/`

### 手動デプロイ

```bash
npm run build
# distフォルダの内容をgh-pagesブランチにプッシュ
```

## 使い方

### デモモード（APIキー不要）
1. アプリを起動
2. 「デモモードで試す」をクリック
3. カテゴリを選択してクイズ開始

### APIモード
1. 「設定」タブでClaude APIキーを設定
2. モードを「APIモード」に切り替え
3. キーワードを入力してクイズ開始

## カスタム問題の追加

`public/quiz-data.json` を編集するか、設定画面からJSONファイルをインポートできます。

```json
{
  "version": "1.0.0",
  "categories": [
    {
      "id": "custom",
      "name": "カスタムカテゴリ",
      "description": "説明",
      "icon": "📝"
    }
  ],
  "questions": [
    {
      "id": "custom_001",
      "categoryId": "custom",
      "question": "問題文",
      "options": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
      "correctAnswer": 0,
      "explanation": "解説",
      "technicalTerms": [],
      "referenceLinks": []
    }
  ]
}
```
